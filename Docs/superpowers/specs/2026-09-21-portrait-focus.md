# 人物选择景深 v5 设计

用户已在对话中确认方案并于 2026-09-21 要求开始修改桌面工程。直接在原目录的开发分支实施，保留已有 Xcode 配置改动。

目标：离线处理单人及 2–4 人照片，点击人物使其清晰，即使其他人距离相同也虚化；改进发丝/肩膀脏边，保持前后遮挡。保留现有导入、裁切、光圈、导出和草稿。

- 默认模型是完整内置 DepthAnythingV3_base_504.mlpackage；V2 保留供调试对照。RGB255 输入，内部归一化；输出深度先转逆深度，校验浮点数组与有效值。504 正方形使用等比补边并将结果映射回原图（以运行探针验证）。
- 深度 PhotoAnalysis 与可选 PortraitAnalysis 在 PhotoSession / SavedDraft 并存，避免把人物编号写入深度。人物缓存绑定照片 SHA256、尺寸及分割版本；重新分割时按焦点位置重新匹配实例，不能沿用任意编号。
- Vision VNGeneratePersonInstanceMaskRequest 在原图处理尺度（最长边2048）生成软蒙版。检查拥挤/检测失败，明确提示退回普通景深，不制造独立人物结果。
- EditRecipe v5 保存 selectedPersonID；单人自动选中，多人默认突出最主要的人并可点击换人。空白点击保留当前人；局部模式仍按原坐标。
- 人物选择优先用高分辨率 coverage，边缘只允许有限吸附。所选人物核心清晰，其他人有虚化下限，背景使用连续深度虚化。取焦深时只采选中人物内部可靠像素。
- 合成前从背景中剔除所有人物，并在有限范围延展背景颜色。人物按深度从远到近以预乘 alpha 合成；失焦人物同时模糊RGB和alpha。保留可见遮挡，不声称恢复真实被遮挡背景或原片失焦细节。
- 模型/人物分析不随点击重复执行。缓存包含人物选择、图片身份及渲染尺寸。导出不带选中轮廓；轮廓只在预览短暂显示。
- iOS17起，无新增外部SDK、无网络推理。真机性能和真实人像轮廓质量须在设备与用户样片验证；模拟器不能代替这项验收。

验收：同深度两人互换清晰；空白点击不换人；细软边保留；前景虚化可遮挡选中的后景人物；禁用景深/f16保留原像素；切换不重复推理；缓存隔离/草稿恢复/裁切坐标正确；模型实际运行与Xcode构建通过。
