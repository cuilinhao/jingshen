# 景深对焦复验

## 自动测试

在 Xcode 选择 PGYDepthDemo Scheme 和 iPhone 模拟器，⌘U。真实模型测试会读取测试包的 FocusScene.png，不能用空模型、占位权重或固定输出替代。测试覆盖近/远焦点切换、同一深度的分离物体、中值采样、无效预测、缓存版本/尺寸、序列化、前景轮廓扩散、原图/裁切与导出。

命令行核心与工程检查：

```sh
swift test
python3 -m unittest discover -s Tests -p test_native_project.py -v
python3 Scripts/validate_project.py
```

## 样图验收

导入原图 yuntu0920.png（测试副本为 Tests/Fixtures/FocusScene.png），自动模式，f2.1，AI 清晰深度范围 0.18。

| 操作 | 期望 |
| --- | --- |
| 点瓶身/瓶颈 | 瓶子、显示器和邻近桌面保持清晰，远处柜子虚化 |
| 点右侧柜门 | 柜子保持清晰，显示器、瓶子和桌面前景虚化 |
| 来回点两处 | 效果明显反转，不重新推理模型 |
| 调大清晰范围 | 更宽深度范围一起清晰 |
| f16 或关闭景深 | 显示原图细节，保留其他编辑效果 |
| 查看深度 | 亮近暗远，与原图方向及裁切一致 |
| 导出 JPEG | 与预览焦平面一致，最长边不超过 2048 |
| 重新启动 | 原图、焦点、参数恢复，当前版本模型缓存可复用 |

对照 xingtu-01.JPG 和 xingtu-02.JPG 主要检查焦平面关系。两者是拍摄屏幕的参考，带透视、反光和拍摄清晰度差异，不能按像素误差评判完全一致。

## 扩展人工验收

- 横图、竖图、EXIF 旋转图在原图/裁切图内点击同一物体，焦点应对齐。
- 导入原生人像深度照片显示原生来源，不误标成 AI。
- 使用本地照片离线首次分析；不需要网络。iCloud 未落地原图需单独处理。
- 透明玻璃、头发、细线和强遮挡检查边界，记录估计误差；必要时调整清晰范围或手动局部模式。
- 连续点击/拖光圈、导入后立即换图、推理失败、导出和取消分享、杀进程恢复检查状态稳定。
- 真机首次加载耗时、连续渲染流畅度、内存和散热需在目标机型测量；模拟器结果不能替代。
