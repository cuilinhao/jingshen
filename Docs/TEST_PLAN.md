# v5 Mac / iPhone 验收清单

本文件列出步骤与预期；未填写实测证据的项目不算通过。执行平台和已经运行的结果见 [VERIFICATION.md](VERIFICATION.md)。

## 1. 构建、模型与离线

记录 Mac、Xcode、模拟器/手机型号及系统版本。打开当前目录 `PGYDepthDemo.xcodeproj`，Scheme 为 `PGYDepthDemo`。确认 Sources 中有 V3 与 V2 两份模型，App Bundle 中生成对应 `.mlmodelc`；不以未编译包代替。项目不应有下载用 Run Script 或远程 Package 依赖。

真机全新安装、保持飞行模式、导入一张已经位于手机本地的照片。确认本机实际推理并记录 `[Model]`、`[Depth]`、`[People]` 日志；不能用复用旧缓存冒充首次推理。分别记录首次模型加载、深度计算、人物识别、预览、导出的耗时与内存。切换 V3/V2 后重复；模拟器 CPU 速度不能代替这一步。

## 2. 人物选择（核心验收）

使用真实单人及 2、3、4 人照片，包含下列场景。用直接导出的 JPEG 对比，不用拍屏摩尔纹判断像素。

| 场景 / 操作 | 预期 | 要记录的问题 |
|---|---|---|
| 单人导入 | 自动选中该人，背景虚化 | 漏检、发丝/衣服外泄色、肩膀光晕 |
| 两人并排且距离相同，交替点击 | 所点人物清晰，另一人仍虚化 | 两人同时清晰、选错、旧预览倒灌 |
| 三至四人轮流点击 | 每次只突出选中者，短暂轮廓对应所选人物 | ID 错乱、合并实例、蒙版缺失 |
| 点击人物间空白 | 保持原人物与焦点 | 跳到最近的人、人物被取消 |
| 头发、肩膀、衣袖、手臂间空隙 | 软边自然，空隙仍属于背景 | 硬切边、糊边、彩边、抠掉肢体 |
| 前排遮挡后排，点击后排 | 前排虚化但保留原遮挡关系 | 后排贴到前排上、前排留下清晰鬼影 |
| 强光逆光、卷发、背景与衣服同色 | 如实记录失败样例 | 不把模型限制记作通过 |
| 超过四人、严重重叠、部分背身 | 检测到不可靠时提示普通景深 | 未被人数检查发现的漏检或合并 |

调大/调小光圈应改变虚化强度；点击和光圈调整过程中 `[Model]` / `[People]` 不应重复运行分析。关闭效果、f16 和原图对比不带本次虚化。不得承诺恢复输入图已有的失焦细节。

## 3. 深度方向与 V2/V3 对照

从文件导入原有 `ReferencePhoto.png`（即 `yuntu0920.png`），使用普通导入路径，不加载人工 fixture。分别选择 V3 和 V2，确认状态中的模型来源、缓存失效与重新计算。无人物时应使用普通深度对焦。

深度图应与原图上下左右对应，亮近暗远。瓶子与墙/柜子的深度应有可见差异；相对数值不是米数。V2 的八个历史点击断言保留于测试，只应用于 V2；不要要求 V3 将显示器和瓶子预测为同一范围。记录每模型的预测差异，而非预设 V3 每张都更好。

检查横图、竖图、超宽图的 V3 补边去除是否正确，内容不被裁掉或压扁，点击边角与深度位置对应。包含 EXIF 90/180/270 度旋转、镜像、透明 PNG、小图及 JPEG/PNG/HEIC。

## 4. 缓存、草稿、裁切

- 保存 v5 草稿、杀进程、重新打开：相同源图、处理尺寸与分析版本应复用深度和人物缓存，恢复所选人物与模型选择。
- 重新生成或让人物缓存失效：保存的焦点应重新命中对应人物，不盲目复用重排后的实例 ID。
- 切换模型：深度模型身份不相同时重新估计深度，仍可复用同图有效人物蒙版；换照片不能复用旧人像。
- 用 v1–v4 草稿覆盖安装测试：保留原图和编辑参数，旧/缺失分析重算，不出现旧“未建立分层”页面。
- 改动源字节、尺寸或分析版本分别检查失效。损坏分析缓存应保留原图；损坏原图应明确报错。
- 裁切后点击人物，确认坐标映射、所选人、轮廓与导出一致；改变裁切不重新运行模型。

## 5. 交互、异常与导出

快速交替点击两人、连续拖光圈，最终结果必须对应最后参数。导入 A 尚未分析完成时改导入 B，最终只显示 B；失败导入保留上一张成功照片。检查取消、权限拒绝、损坏文件和过大文件反馈。

导出 JPEG / SDR / sRGB，最长边不超过 2048、小图不放大，无轮廓/对焦框/UI/GPS；方向、裁切和前后遮挡与预览一致。多人导出注意更高分辨率下的虚化半径、边缘延展和内存。分享与保存相册分别操作。

## 6. 自动检查

```sh
swift test
python3 -m unittest discover -s Tests
python3 Scripts/validate_project.py
```

Xcode **⌘U** 运行核心、图像、流水线与 Core ML 测试，查看 `.xcresult` 中合成边缘、深度渲染等附件。`CoreMLSmokeTests` 使用真实模型，不因缺失跳过；`PortraitImagingTests` 使用人工可控图形检查同深度选择、边缘泄色、前景扩散、分数 alpha 线性重建、贴边透明衰减和关闭效果。

TestAction 的 `PGY_SKIP_UI_STARTUP_FOR_TESTS` 只抑制 UI 启动额外的样图分析；普通 ⌘R 不设该变量。`Scripts/Verify_on_Mac.sh` 仅做模拟器 SDK 构建，不等于运行测试、实机签名安装或人物画质验收。
