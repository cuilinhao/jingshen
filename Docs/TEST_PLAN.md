## 四、非参考图片与坐标

另外用至少5张场景，不要只有参考照片：多人/多物体、人物加远处背景、没有显著前景、玻璃和反光、细线复杂边缘。记录AI错误，不将语义分组当作物理距离保证。

分别导入 JPEG / PNG / HEIC；EXIF旋转90/180/270、镜像、横图/竖图/超宽图/小图/透明PNG；点击四角、图像外的黑边以及裁切后照片。预期焦点位置和深度图始终对齐，黑边不产生焦点，裁切不改变原图深度坐标。

## 五、交互、导出、异常

连续拖动刻度、交替快速点击瓶子/柜子，最后结果须对应最后参数，无旧任务倒灌。导入A尚在推理时改导入B，最终只显示B；失败导入保留上一次成功照片。相册取消 / 无权限 / 文件过大 / 损坏文件均明确处理。

关闭效果 / f16 / 对比原图：没有本次虚化；比对保持相同裁切。范围调宽更多相近深度清晰、调窄减少；该滑杆不是局部圆圈半径。局部圆圈仅在明确选“局部”模式后存在。

导出JPEG最长边不超过2048且不放大小图，方向/颜色正确，不含UI/GPS，预览导出景深一致。检查照片权限拒绝与分享路径。
