# PGYDepthDemo · 原生主体虚化版 v2

**这次不需要下载模型。**工程已移除旧版模型下载构建阶段、下载脚本、外部模型资源及其运行时加载代码。普通照片改用苹果系统 Vision 识别主体，再用 Core Image 生成虚化；照片有可用的原生深度时仍优先读取。

请把本压缩包解压到**新文件夹**，不要覆盖旧目录，也不要继续打开旧版工程。

## 用 Xcode 打开

1. 双击 **`PGYDepthDemo.xcodeproj`**，不是 `Package.swift`。
2. Scheme 选择 **PGYDepthDemo**，选择 iPhone 或已安装的 iPhone 模拟器。
3. 真机：在 **Signing & Capabilities → Team** 选择自己的开发团队；必要时修改 Bundle Identifier。
4. 按 **⌘R**。不需要提前运行脚本，不需要拉取 Swift Package、安装第三方 SDK，或准备模型文件。

最低部署版本 **iOS 17.0**；Swift 5 语言模式，工程格式按 Xcode 15+ 编写。请使用带有相应 iOS SDK 的完整 Xcode。真机签名、系统开发支持组件与 SDK 的安装属于 Xcode 环境准备，不是本 Demo 的模型依赖。

**建议用真机验证主体识别。**模拟器或设备上的 Vision 请求可能失败；此时 Demo 会显示“局部虚化”，而不是阻止导入或要求下载资源。

## 本次改动

| 项目 | 新版本 |
|---|---|
| 模型依赖 | 无外部 `.mlpackage` / `.mlmodel` / `.mlmodelc`；无模型下载阶段 |
| 普通照片 | `VNGenerateForegroundInstanceMaskRequest` 识别主体并缓存软蒙版 |
| 点击主体 | 选中主体保持清晰，其他区域虚化 |
| 点击背景 | 背景保持清晰，已识别前景主体虚化 |
| 光圈尺 | 固定橙色指针，灰色刻度滚动；f 值越大，虚化越弱 |
| 原生深度 | 读取照片自带辅助深度 / 视差，保留原生景深路径 |
| 识别失败 | 明确显示“局部虚化”；圆形选区内清晰、周围虚化，可调范围 |
| 手动模式 | 细调中可主动选择“局部虚化”，不把圆形选区伪装成主体识别 |
| 蒙版预览 | 原生模式显示相对深度；主体/局部模式显示白色虚化、黑色清晰 |
| 草稿 | 原图 + 带类型的分析缓存 + v2 配方；兼容迁移上一版编辑参数 |
| 界面 | 保留上一版按录屏搭建的主界面布局和控件；状态文案如实说明当前算法 |

这里的“无需下载模型”指**开发者不需要下载和携带独立模型文件，App 也没有模型下载逻辑**。Vision 仍然属于苹果提供的机器学习能力，并不是“完全不用系统模型”。

## 启动后怎么试

默认打开录屏裁切样片；有完整草稿时恢复最近一张照片。

- 右上角“…”：相册/文件导入、查看深度或虚化蒙版、重新识别、保存草稿、重置。
- 点照片切换清晰区域；长按或点底部双框图标比较原图。
- 拖动光圈尺：向左拖增大 f 值、减弱虚化，向右增强；f16 对应本 Demo 的零虚化强度。
- 底部“调整”：选择自动/局部模式，调效果强度、边缘羽化、局部范围或原生深度容差、曝光。
- 右下角导出：保存相册、分享/存储到文件、保存可编辑草稿。

导出为 **JPEG / SDR / sRGB，最长边最多 2048 像素，小图不放大**。不会导出对焦框、控件或 GPS。关闭效果保留主动设置的裁切/色调/曝光；原图对比关闭全部效果但保持相同裁切，避免画面跳动。

仅保留最近一张照片的草稿，不是多照片项目管理器。旧版 v1 的原始数据和编辑参数会迁移；旧外部模型的 `depth.json` 不会被误当成原生深度复用。

## 离线验收

先保证 Xcode 和需要的 SDK/模拟器已经安装。新目录中的工程没有联网构建步骤。

真机安装后，使用**已在手机本地的照片**，在断网状态首次执行主体识别、点击切换、调光圈并导出。请同时确认界面显示的是“系统主体虚化”，不是“局部虚化”，两条路径必须分别验收。仅在 iCloud 中的照片需要先让系统取回；本 Demo 不负责远程照片获取。

## 画质边界

普通照片走的是**主体分割模拟景深，不是整张照片的深度估计**。系统可能合并多个相邻对象，也可能识别不到透明瓶子、细线或复杂轮廓。不同主体编号不表示不同远近，代码没有把编号当成深度值。

点背景会把所有未识别为前景的区域作为一个背景区域，不会为背景里的每张桌子、每个人自动提供独立焦平面。超过 16 个主体时，前 15 个保留独立选择，其余按一个组处理，以限制内存；界面会提示合并数量。

分割分析及缓存软蒙版最长边为 1024；导出到 2048 时会放大蒙版。边缘有羽化和前景扩散修正，但不重建被遮挡的背景，也不保证消除所有光晕。已失焦的原始细节不能靠后期“重新对焦”恢复。

内置样片来自视频裁切，可能已有虚化；请导入自己的清晰照片测试。`Docs/VideoReference.png` 是录屏参考帧，**不是工程运行截图**。主页面几何参数已保留，尚未通过真机逐像素比对；录屏没展示的展开面板是 Demo 补充设计。

## 排错

若仍看到“景深模型下载失败”或 `Build Depth Model`，说明打开的还是旧工程；新工程的 Build Phases 中只有 Sources、Frameworks、Resources。

若状态显示“局部虚化”，右上角“实现说明 / 离线说明”会显示系统识别错误，可换一张主体清晰的本地照片并点“重新识别主体”。请优先在真机检查，而不是用模拟器识别结果判断最终画质。

控制台日志：`[Subjects]` 系统主体识别/回退、`[Depth]` 原生深度、`[Focus]` 选择、`[Draft]` 草稿、`[Export]` 导出。编译问题请保留第一条红色错误及上下文。
